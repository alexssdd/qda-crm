# AI-модерация заказов

Модуль проверяет уже опубликованные заказы и не меняет их статус или содержимое.
Результат сохраняется в существующей ленте событий заказа:

- `moderation.completed` — проверка выполнена;
- `moderation.failed` — проверка не выполнена и нужен ручной повтор.

Поле `order_event.message` строится CRM из фиксированных русских шаблонов. Строгий
результат модели, сигналы истории, идентификаторы связанных заказов и usage
сохраняются в `order_event.data`. Автоматические действия в первой версии не
выполняются.

## Конфигурация

Global и CRM используют общую БД и таблицу `config`. CRM читает группу
`openai` в namespace `global/global` через существующий `ConfigService`;
отдельная синхронизация не требуется.

`config.encryption.keys['global']` в Global должен совпадать с
`config.encryption.key` CRM, чтобы обе стороны работали с одним encrypted
значением. При инициализации OpenAI-клиента модуль очищает локальный CRM
FileCache только для группы `openai`, поэтому добавление или ротация ключа в
Global видны следующему запуску модерации без отдельного sync.

API-ключ добавляется на Global скрытой интерактивной командой:

```bash
cd /var/www/global-api
php yii config/set-secret global global openai api_key
```

Ключ не передаётся параметром команды, не записывается в логи и не добавляется
в репозиторий. Модель по умолчанию — `gpt-5.6-luna`; её параметры задаются в
конфигурации модуля `moderation` в `config/console.php`.

## Запуск

Пакет опубликованных заказов за последние семь дней:

```bash
php yii moderation/order/run
```

Один заказ:

```bash
php yii moderation/order/run --order-id=123
```

Повтор после исправления конфигурации или ручного решения:

```bash
php yii moderation/order/run --order-id=123 --force=1
```

Автоматическую модерацию достаточно запускать на одной CRM-ноде; каждый заказ
дополнительно защищён DB mutex.

```cron
* * * * * flock -n /tmp/qda-crm-moderation.lock php /var/www/crm/yii moderation/order/run --limit=20
```

В OpenAI не отправляются имя клиента, телефон и координаты. Телефон используется
только локально для подбора истории; контакты внутри свободного текста
заменяются маркерами `[phone]`, `[email]`, `[url]`, `[handle]`, а похожие на
координаты пары — `[coordinates]`. Сигнал обхода площадки сохраняется без
раскрытия значения. Из произвольного `extra_fields` передаются только явно
разрешённые `loaders_count` и `scheduled_at`. Наружу уходит необратимый HMAC
`safety_identifier`.
